# 🌙 SleepTrack

**SleepTrack** es una aplicación Android desarrollada en Java y Firebase para registrar y analizar los hábitos de sueño.

## 📱 Funcionalidades

- Alarmas y horarios de descanso.
- Registro de horas de sueño.
- Estadísticas y análisis de patrones.
- Seguimiento de hábitos diarios.
- Asistente de sueño con recomendaciones personalizadas.
- Autenticación y almacenamiento mediante Firebase.

## 📥 Descargar SleepTrack

Descarga la última versión del APK desde la sección **Releases** de este repositorio.

[Ver versiones disponibles](https://github.com/jgdolores24/SleepTrack-Public/releases)

## 📲 Instalación

1. Descarga el archivo `.apk` desde Releases.
2. Ábrelo en tu dispositivo Android.
3. Autoriza la instalación desde esa fuente si Android lo solicita.
4. Instala y abre SleepTrack.

## 🛠️ Tecnologías

Android Studio · Java · XML · Firebase Authentication · Cloud Firestore
